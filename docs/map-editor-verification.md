# 设定编辑器与创作地图交付记录

日期：2026-09-07。本记录描述实现与本地验证范围；线上发布状态以对应提交的 GitHub Pages 部署结果为准。

## 使用入口

- 设定集 → 新建地图：默认空白画布，也可上传 PNG / JPG / WebP 底图。
- 放置标记 → 点击画布，或直接“在中央添加”。标记可拖动、关联已有地点、创建地点、关联组织总部/分部/据点。
- 从标记打开资料；地点/组织档案有“在地图中查看”入口。
- 小说概览 → 查看设定与地图：默认按当前小说过滤。
- 关闭保留本机草稿，丢弃草稿明确放弃编辑。点击保存后才参与现有项目云同步。

## 已验证

- `npm run test:maps`：7 项通过。两部小说共享地图时分别过滤标记、地点和组织；不自动扩展引用。删除地图保留地点/组织；删除地点或组织清理对应地图关联。误标公开的地图也不进入快照。上传地址合并不覆盖新正文、标记或重新引入已删除附件。
- 在隔离的浏览器会话中操作本地工作台，未使用用户云端登录态或修改用户浏览器中的创作数据。
- 空白地图点击放置标记、新建关联地点、打开地点编辑、保存并返回原地图。
- 实际上传 PNG 到 IndexedDB；刷新后仍加载底图；拖动后的未保存坐标约为 `(0.6136, 0.5807)`，刷新恢复后画布测量坐标约为 `(0.6135, 0.5807)`，差异为画布边框及子像素取整。
- 新地图未保存即刷新：在列表“继续草稿”入口恢复；丢弃后确认草稿记录清除。
- 中英文逗号标签输入与保存，保存后去掉空标签。
- 组织总部关联、组织档案返回地图；小说视图隐藏未关联组织，编辑备注后返回全部资料，该组织引用仍保留。
- 角色三个分区切换以及刷新后重新打开，别名草稿保留；媒体区仍读取原角色素材。
- 1440×1000、820×1180、390×844 视口。平板/窄屏无横向溢出；窗口变化后底图在画布范围内完整适配。820px 宽度下，设定属性默认折叠，正文输入区域高度约 496px。
- 页面验证期间浏览器没有运行时异常。
- 本地构建、公开站与云端工作台构建、公开产物私密标记检查、类型检查和 diff 空白检查通过。

## 验证边界与保留事项

- 本轮未进行真实 Supabase 账号下的双设备上传/下载验收；已接入现有私有存储与项目保存路径，验证了本机附件和上传结果合并逻辑。草稿仍仅在当前浏览器，不参与云同步。
- 平板验证采用浏览器视口模拟；未实测 iPad Safari 的软键盘和双指手势。
- 构建保留工作台单包超过 500 kB 的体积提示，不影响构建成功。
- 地图目前只用于私密创作，公开读者地图、站内生图、地形绘制和路线/疆域编辑未纳入本轮。
- 移除地图只清理项目附件元数据，不物理删除底图文件，避免破坏旧版本或复制地图的引用。本机草稿用过的附件也不会自动清除。
- 图片视频库沿用即时保存逻辑；丢弃人物设定草稿不会撤销媒体库操作。
